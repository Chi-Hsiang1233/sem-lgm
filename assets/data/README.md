# 範例資料

| 檔案 | 來源 | 用途 |
|---|---|---|
| `demo_growth.csv` | lavaan 內建的 `Demo.growth`（只加上 `id`） | 主要範例：步驟一到六 |
| `demo_growth_missing.csv` | **為示範而模擬，不是真實資料**（由 `demo_growth.csv` 加工） | 遺失機制檢驗、多重插補敏感度分析 |
| `demo_items.csv` | **為示範而模擬，不是真實資料** | 各波信度 |
| `demo_growth_missing_x.csv` | **為示範而模擬，不是真實資料**（由 `demo_growth_missing.csv` 加工） | 預測變數有遺失值時：FIML 與多重插補 |

後三份由 `scripts/make_demo_data.R` 產生（固定亂數種子，可重現）：在 skill 根目錄執行 `Rscript scripts/make_demo_data.R`。

## demo_growth.csv

lavaan 套件內建的 `Demo.growth`，匯出時只在第一欄加上 `id`，其他數值未修改。

- 這是 lavaan 提供的**模擬資料**，變數沒有實質意義，也沒有公開的真實參數。
- N = 400，沒有遺失值。

| 欄位 | 內容 | 角色 |
|---|---|---|
| `id` | 編號 | 識別 |
| `t1`–`t4` | 4 波重複測量 | 結果變數 |
| `x1`、`x2` | 不隨時間改變的連續變數 | 時不變預測變數 |
| `c1`–`c4` | 每波各有一個值 | 時變共變數 |

重新匯出：

```r
d <- lavaan::Demo.growth
write.csv(cbind(id = seq_len(nrow(d)), d), "demo_growth.csv", row.names = FALSE)
```

這份資料無法示範的部分：測量恆等性（單一分數）、遺失處理（沒有遺失）、真正的分組比較（沒有類別變數；步驟五以 `x2` 中位數切分只作為機制示範）。

## demo_growth_missing.csv（為示範而模擬，不是真實資料）

在 `demo_growth.csv` 上製造 **MAR 流失**：

- 第 2–4 波，前一波（已觀察到的）分數越低，這一波越可能流失；流失後不再回來（單調遺失）。
- 有遺失者 90 人（22.5%）；各波遺失：t2 42 人、t3 65 人、t4 90 人；t1、x1、x2、c1–c4 沒有遺失。
- 新增 `aux`：模擬的**輔助變數**，與第 3、4 波分數有關、沒有遺失，用來示範 `--aux`。
- 因為流失只由已觀察到的分數決定，這份資料符合 MAR；真實資料無法確認這一點。

## demo_growth_missing_x.csv（為示範而模擬，不是真實資料）

以 `demo_growth_missing.csv` 為基礎（結果變數的 MAR 流失與 `aux` 相同），再讓時不變預測變數有遺失（固定亂數種子 20261114）：

- `x1`：完全隨機遺失，約 10%。
- `x2`：`aux` 越低越容易遺失（MAR），約 16%。
- 用來示範確認點 3 之後的追問「遺失值怎麼處理？」：FIML（預設）｜多重插補。

## demo_items.csv（為示範而模擬，不是真實資料）

- N = 400，4 波 × 4 題，每題 1–5 分；`s_t1`–`s_t4` 是各波 4 題的總分。
- 題目欄位 `s_t{波}_i{題}`，例如 `s_t2_i3` 是第 2 波第 3 題。
- 第 4 波第 4 題（`s_t4_i4`）刻意設定為鑑別度很低，用來示範信度偏低與題目–總分相關偏低的判讀。
- 只用來示範各波信度；總分沒有設計成長趨勢，不適合拿來估計成長模型。
