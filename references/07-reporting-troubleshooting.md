# 報告與問題排除

## 1. 報告清單

**設計與資料**
- [ ] 波數、實際測量時間、時間編碼與時間 0 的位置（`--anchor`）；截距相關參數是否對截距位置敏感
- [ ] 每波 N、保留率、遺失值分析結果（遺失比例、Little 的 MCAR 檢定、流失者比較、前一波分數是否預測遺失）
- [ ] 遺失處理（FIML）與 MAR 假設；有用輔助變數時列出；預測變數有遺失、選多重插補時，報告 m、插補模型的變數、插補結果與 FIML 的差異，以及插補下未提供的比較
- [ ] 測量：各波信度（α、ω，有題目資料時）；只有總分時說明無法計算；測量恆等性能否檢驗

**模型建立**
- [ ] 比較過的所有軌跡形式（配適、BIC、LRT），採用的理由；確認點 1 直接指定單一模型時，寫明「未做形式比較」與提醒過的問題
- [ ] 判定配適與比較模型所用的門檻與出處（`09-fit-criteria.md`）
- [ ] 殘差結構的檢定
- [ ] 估計法（MLR）與軟體版本

**結果**
- [ ] 最終模型配適：χ²、df、p、CFI、TLI、RMSEA（90% CI）、SRMR
- [ ] 成長因子平均（附單位）、變異、相關
- [ ] 預測變數的 b、SE、95% CI、β；解釋變異量
- [ ] 時變共變數：等同限制的檢定結果
- [ ] 假設診斷的摘要
- [ ] 圖：個體軌跡、預測軌跡

**解讀**
- [ ] 平均與個別差異分開敘述
- [ ] 不以因果語言描述觀察性結果

`sensitivity_mi.R`（`run_pipeline.R --missing mi`）產生 `sensitivity_mi/mi_report.md` 與 `mi_comparison.csv`；匯出 qmd 時會加一節「預測模型：多重插補（主結果）與 FIML 對照」。

`step6_report.R` 會產生 `analysis_report.md`（所有步驟的結果、各模型的評估指標表，最後附最終模型摘要），評估指標另存為 `fit_all.csv`。

`export_qmd.R`（`run_pipeline.R` 最後會自動執行）產生 `lgm_analysis.qmd`：各步驟的摘要與圖，加上每個模型的 lavaan 程式碼與 `summary()` 輸出（程式碼預設摺疊、summary 可展開），以及配適指標表與 LRT。加 `--render` 渲染成 HTML。qmd 用相對路徑讀 `step*/analysis_data.rds` 與各步驟的報告，所以要和輸出資料夾放在一起。

## 2. 常見問題

決策流程圖見 `00-flowcharts.md` 第 7 節。

| 症狀 | 常見原因 | 處置 |
|---|---|---|
| 二次項或斜率變異為負 | 真實變異接近 0、軌跡誤設 | 固定該變異為 0 並與自由模型比較；改用較簡單的形式 |
| 截距與斜率相關接近 ±1 | 時間 0 位置、天花板效應 | 改用 `--anchor mid` 或 `last`；檢查分配 |
| 不收斂 | 量尺差異、起始值不佳、模型過度參數化 | 重新量尺化；簡化形式；手寫語法時用 `start()` 給起始值，或 `control = list(iter.max = 5000)` |
| 適配差但隱含平均吻合 | 殘差結構錯誤 | 殘差變異自由估計；有理論時加入相鄰波殘差相關 |
| 適配差且隱含平均不吻合 | 形式錯誤 | 改試二次或潛在基底 |
| 無成長模型出現負殘差變異 | 模型嚴重誤設 | 正常現象，因為資料明顯在變 |
| 加入預測變數後 N 變少 | 預測變數有遺失、fixed.x = TRUE | 腳本會自動改用 fixed.x = FALSE；或插補預測變數 |
| fixed.x = FALSE 後配適變差 | 外生變數之間的共變被固定為 0 | 腳本已自動列出所有外生變數的共變；手寫語法時要自行加入 |
| 數值很大（上千）不收斂 | 量尺差異 | 重新量尺化；時間單位改成年或月 |
| 潛在基底的負荷超出範圍 | 軌跡非單調 | 考慮二次模型 |
| LRT 與 BIC 結論不同 | 兩者懲罰不同 | 兩個都報告，說明採用的理由 |
| 某一步失敗 | 參數、欄位名稱、套件 | 看 `stepN.log` 的錯誤訊息 |
| 某一波信度偏低（α 或 ω < .70） | 題目鑑別度低、題目在該波意義改變、樣本在該波同質性高 | 看校正後題目–總分相關找出問題題目；刪修題目或改用二階成長模型；說明該波殘差變大、估計較不精確，若殘差變異設為相等還會造成偏誤 |
| FIML 與多重插補的結果不同（差異 > 1 個 SE） | 插補模型多用了輔助變數、插補模型漏掉分析模型的變數或交互作用、遺失比例高 | 確認插補模型包含分析模型所有變數（含交互作用、分組）；讓 FIML 也納入輔助變數（飽和相關法）；兩種結果都報告；MNAR 時在限制中說明 |
| `sensitivity_mi.R` 顯示略過 | 沒有遺失值，或缺少 mice 套件 | 沒有遺失值時不需要做；缺 mice 時用 `check_env.R --install-optional` |
| `--stage predictors` 停下來，列出預測變數的遺失 | 加入的預測變數有遺失值，還沒選處理方式 | 問使用者 FIML（預設）或多重插補，再加 `--missing fiml` 或 `--missing mi` 重跑 |

## 3. 解讀提醒

- 斜率要帶單位：「每年增加 1.01 分」，而不是「斜率為 1.01」。
- 截距要說明時間 0：「第一波的平均為 0.62」。
- 變異顯著代表個別差異存在，不代表每個人都在變。
- 相關是個體間的關聯：「起點較高的人，增加得也較快」。
