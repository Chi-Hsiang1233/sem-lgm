## 1. 模型與參數

SEM 把成長模型寫成受限的因子模型：

y = Λη + u，η = α + ξ

- Λ 是固定的時間負荷，定義成長因子的意義。
- α 是成長因子平均：整體的起始水準與變化率。
- Ψ 是成長因子的變異共變：個別差異的大小，以及起點與變化率的關聯。
- Θ 是殘差變異：各波偏離個人軌跡的程度。

```
i =~ 1*t1 + 1*t2 + 1*t3 + 1*t4
s =~ 0*t1 + 1*t2 + 2*t3 + 3*t4
```

lavaan 的 `growth()` 會自動把觀察變數截距固定為 0，並估計成長因子的平均。

## 2. 軌跡形式

| 形式 | 時間負荷 | 至少幾波 | 用途與注意 |
|---|---|---|---|
| 無成長 | 只有截距 | 2 | 比較基準 |
| 線性 | 0, 1, 2, … | 3（建議 ≥ 4） | 預設起點 |
| 二次 | 加 0, 1, 4, 9, … | 4 | 加速或減速；二次項變異常接近 0 而產生負變異數 |
| 潛在基底 | 首尾固定，中間自由 | 4 | 不預設形式；負荷表示累積變化比例；不能外推 |

**選擇依據**（`step2_unconditional.R` 都會輸出）：

1. 「可採用」欄：有負變異數的模型不能選。
2. 「整體配適」欄（整體配適門檻）與「比較結論」欄（模型比較門檻）：門檻與出處見 `09-fit-criteria.md`。BIC 差距 < 2 證據微弱（Raftery, 1995）。
3. 巢套 LRT：線性 vs 二次、線性 vs 潛在基底。
4. 潛在基底的負荷是否接近線性時間。
5. 隱含平均與樣本平均的差距（`implied_vs_observed.png`）。
6. 理論：形式要能解釋。

**比較規則的細節**

- 巢套關係：無成長 ⊂ 線性 ⊂ 二次；線性 ⊂ 潛在基底（線性 = 潛在基底的中間負荷固定為線性時間）；殘差變異相等 ⊂ 殘差變異自由估計。
- MLR 時 `lavTestLRT()` 自動使用尺度校正（Satorra–Bentler）的差異檢定；不要手動相減 scaled χ²。
- LRT 顯著但改善很小（ΔCFI ≤ .01、ΔBIC < 2）時，偏好較簡約的形式。ΔBIC > 10 是非常強的證據（Raftery, 1995；完整門檻見 `09-fit-criteria.md`）。
- **確認點 1 直接指定成長模型時**（`--forms`）：只估計指定的形式。只指定一個時不做形式比較（沒有比較表、LRT 與潛在基底的參考比較），報告與 `recommendation.txt` 註明「未做形式比較」；`form_check.txt` 列出要提醒使用者的問題（CFI < .90 或 RMSEA ≥ .10、不收斂或負變異數、各波殘差平均有系統性偏離）。指定兩個以上時，只在指定的形式中依同樣的規則建議。
- 非巢套比較（二次 vs 潛在基底）只能用 AIC/BIC。
- **以潛在基底為基準**（步驟二的「B. 以潛在基底模型為基準的比較」，`baseline_comparison.csv`）：潛在基底不預設形狀，先讓資料決定形狀，再看無成長、線性、線性＋殘差變異相等加上限制後會不會明顯變差（LRT；p 不顯著代表沒有變差），以及 ΔAIC、ΔBIC（該模型 − 基準，負值代表比基準好）。二次與潛在基底不是巢套關係，只比 ΔAIC、ΔBIC。首尾負荷固定為 0、1 時，斜率代表整段期間的總變化量，中間負荷是累積變化比例；報告中的「累積變化比例」就是這個換算，與線性預期（1/3、2/3……）比較。
- **邊界值問題**：檢定「斜率變異 = 0」（例如無成長 vs 線性，或固定斜率變異為 0 的模型）時，變異不能小於 0，LRT 的分配是卡方的混合分配，一般 p 值偏保守；常用近似是把 p 除以 2（Stoel et al., 2006）。

## 3. 識別與配適

- df = 獨特動差數 − 自由參數數。4 波時有 4 個平均 + 10 個變異共變 = 14 個動差。線性模型（殘差變異自由估計）估計 2 平均 + 3 變異共變 + 4 殘差 = 9 個參數，df = 5。
- 配適：χ²、CFI、TLI、RMSEA（90% CI）、SRMR。判準要依樣本數與變數數調整，不要當成硬性門檻（Hair）。
- 負變異數（Heywood case）代表模型與資料不符，常見於二次項或過度設定的模型。

## 4. 殘差結構

- **殘差變異自由估計**：SEM 的預設，假設最少。
- **殘差變異相等**：對應多層次模型的同質變異假設；在 SEM 中這是可以檢定的限制。
- `step2_unconditional.R` 以 LRT 比較；不顯著時採相等（較簡約），兩者的成長參數通常差異很小。
- 殘差結構會影響成長因子的變異共變估計，所以要先決定再加入預測變數。
- 進階：相鄰波殘差相關（`y1 ~~ y2`），適用於有短期相依時，但會和斜率變異競爭。

## 5. 假設診斷

`step2_unconditional.R` 以因子分數計算每人的預測軌跡與殘差：

| 輸出 | 看什麼 |
|---|---|
| `residual_plot.png`、各波殘差平均 | 平均應接近 0 且沒有規律；有 U 型或系統趨勢代表未建模的非線性 |
| 各波殘差 SD | 差異大代表殘差變異不等，應用殘差變異自由估計 |
| `predicted_trajectories.png` | 個人軌跡是否合理、有沒有極端的人 |
| 因子分數的偏態峰度與離群值 | 成長因子的常態假設、可能的離群個案 |

因子分數有縮減，只作為檢查工具，不要拿來做後續的迴歸或分組。

## 6. 時間編碼與截距位置

時間負荷 = 實際時間 − anchor。移動 anchor 是同一個模型的重新參數化：

| 會改變 | 不會改變 |
|---|---|
| 截距平均、截距變異、截距–斜率共變與相關、預測變數對截距的效果 | 整體配適（χ²、CFI、RMSEA……）、斜率平均與變異、殘差 |

| `--anchor` | 時間負荷（4 波等距） | 截距代表 |
|---|---|---|
| `first`（預設） | 0, 1, 2, 3 | 起始水準 |
| `last` | −3, −2, −1, 0 | 結束時的水準 |
| `mid` | −1.5, −0.5, 0.5, 1.5 | 追蹤期中點；常可降低截距–斜率相關 |

- 依研究問題選：關心起點（基線差異）用 first；關心介入結束後的結果用 last。
- 步驟二的「F. 時間編碼敏感度」自動把截距移到另一端重估，輸出 `time_coding_sensitivity.csv`。若兩端的截距–斜率相關正負號不同，在報告中說明這個相關依賴時間 0 的位置，不要過度解讀。
- 二次模型中，線性項 s 的意義是「anchor 那一刻的瞬時變化率」，也會隨 anchor 改變。
