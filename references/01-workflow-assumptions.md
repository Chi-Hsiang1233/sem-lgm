# 分析流程與模型假設總表

本檔把潛在成長模型需要的假設、檢查方式與違反時的處理整理在一起，並標出對應的步驟腳本。出處為 Grimm, Ram, & Estabrook (2017) 與 Hair, Black, Babin, & Anderson (2019)。

## 目錄
1. 流程總覽
2. 假設總表
3. 模型的統計假設

## 1. 流程總覽

```
研究問題（什麼在變？用什麼時間尺度？）
  → 準備資料（長格式先轉成寬格式）
  → 步驟 1：資料篩檢（各波信度 → 遺失機制檢驗 → 各波描述與軌跡）→ 確認點 1
  → 步驟 2：無條件模型（估計並比較形式 → 確認點 2 → 殘差結構 → 假設診斷 → 時間編碼敏感度）→ 確認點 3；一律用 FIML
  → 步驟 3：時不變預測變數（誰的起點高、誰變得快）
  → 步驟 4：時變共變數（同一波的因素）
  → 步驟 5：多群組（群組差異；檢驗步驟 3 的假設）
     （步驟 3–5 加入的預測變數有遺失值時，追問 FIML（預設）或多重插補）
  → 步驟 6：彙整結果 → 匯出 qmd 報告
```

圖形版本（含每一步的決策樹）見 `00-flowcharts.md`。用自己的資料一次跑完：`scripts/run_pipeline.R`。

Grimm 建議先描述再解釋：先把「怎麼變」描述清楚（步驟 2），再問「為什麼不同」（步驟 3–5）。無條件模型的形式錯了，後面的預測結果也會跟著錯。

## 2. 假設總表

| 假設 | 怎麼檢查 | 違反時的處理 | 步驟 | 出處 |
|---|---|---|---|---|
| 每一波的分數可信 | 各波 α、ω、校正後題目–總分相關（`--items`；不要用重測信度） | 刪修題目；改用二階成長模型；或說明限制 | 1 | Grimm；McDonald |
| 分數對改變敏感，沒有天花板或地板 | 各波分配、極端值比例 | 換用原始或 IRT 分數；不要用常模化分數 | 1 | Grimm |
| 量尺跨時間相同（測量恆等性） | 多題時做縱貫恆等性；單一分數時無法檢驗 | 多題時用因子曲線模型（sem-longitudinal） | 1 | Grimm |
| 時間是等距尺度、編碼反映實際間隔 | 確認測量時間 | 用 `--times` 給實際時間、`--anchor` 設定截距位置；每人時間不同時本 skill 不適用（見 SKILL.md「模型限制」） | 1、2 | Grimm |
| 遺失為 MCAR 或 MAR | 遺失比例與涵蓋率、Little 的 MCAR 檢定、流失者比較、前一波分數是否預測遺失 | FIML（預設）加輔助變數（`--aux`）；預測變數有遺失時可選多重插補（`--missing mi`，`sensitivity_mi.R`）；MNAR 無法檢驗，在限制中說明 | 1 | Little；Enders；Grimm |
| 模型可識別 | df > 0；沒有負變異數 | 減少自由參數；3 波只估線性 | 2 | Hair |
| 軌跡形式正確 | 比較形式、殘差平均是否有規律 | 改用二次或潛在基底 | 2 | Grimm |
| 殘差變異相等（若如此設定） | LRT 比較相等與自由估計 | 改用殘差變異自由估計 | 2 | Grimm |
| 殘差與成長因子為常態 | 殘差圖、因子分數的偏態峰度 | MLR（預設）；嚴重時考慮其他分配 | 2 | Grimm；Hair |
| 所有人來自同一母體 | 多群組比較、檢查因子分數分配 | 多群組模型；成長混合（sem-longitudinal） | 2、5 | Grimm |
| 所有人遵循同一軌跡形式，且殘差變異與共變不隨預測變數改變 | 多群組 M2–M4 比較 | 報告群組差異；分組建模 | 3、5 | Grimm |
| 時變效果跨波相等（若如此設定） | LRT 比較相等與自由 | 各波自由 | 4 | Grimm |
| 時變共變數與成長因子不相關（多層次的預設） | SEM 中放寬並以 LRT 比較 | 讓兩者相關；若兩者都是內生變數，改用平行歷程模型 | 4 | Grimm |
| 要推論因果 | 共變、時間順序、非虛假、理論支持 | 改寫為關聯；考慮實驗或滯後設計 | 6 | Hair |

## 3. 模型的統計假設

以線性模型 y_ti = η0i + λt·η1i + e_ti 為例：

- e_ti ~ N(0, θt)；(η0i, η1i) 服從多變量常態，平均 (α0, α1)、變異共變 Ψ。
- Cov(e_ti, η_ki) = 0；不同波次的殘差彼此不相關。

| 假設 | 意思 | 不成立時的後果 |
|---|---|---|
| 軌跡形式正確，且所有人形式相同 | 每個人都遵循同一種函數形式，只是截距、斜率的值不同 | 殘差有系統性趨勢，成長因子的平均與變異都會偏誤 |
| 殘差平均為 0 | 每一波，觀察分數平均而言落在個人軌跡上 | 代表有未建模的非線性 |
| 殘差常態分配 | e_ti 服從常態分配 | ML 的標準誤與 χ² 失準；MLR 可部分校正 |
| 殘差跨時間不相關 | 波次間的關聯完全由成長因子解釋 | 短期相依會被誤當成斜率變異 |
| 殘差變異的結構（若設定相等） | θ1 = θ2 = … | 影響成長因子變異與共變的估計；可放寬為殘差變異自由估計並檢定 |
| 成長因子為多變量常態 | 截距與斜率在母體中服從多變量常態 | 偏態或離群個案讓變異共變估計不穩定 |
| 殘差與成長因子不相關 | 偏離個人軌跡的程度與起點、變化速度無關 | 參數估計偏誤 |
| 個體之間相互獨立 | 不是同一家庭、同一班級的巢套資料 | 標準誤低估；要另外處理叢集結構 |
| 所有人來自同一個母體 | 只有一組成長因子的平均與變異 | 平均軌跡可能不代表任何人；需要多群組或成長混合模型 |
| 模型可以識別 | df ≥ 0，例如 3 波只能估線性 | 無法估計或出現負變異數 |

**加入時不變預測變數後**：預測變數與成長因子為線性關係、預測變數沒有測量誤差；不論預測變數的值，所有人遵循同一種軌跡形式；成長因子的殘差變異共變與觀察分數的殘差變異不隨預測變數改變（類別型預測變數可用多群組 M2 → M3 → M4 檢驗）；截距與斜率平均是預測變數都等於 0 時的值。

**加入時變共變數後**：效果跨波相等（若如此設定，可用 LRT 檢定）；時變共變數與成長因子不相關（可放寬並檢定）；效果是同一波的關聯，方向沒有被檢驗，互相影響時改用平行歷程模型。

**估計的前提**：ML 與 MLR 的標準誤和檢定都是大樣本近似；ML 假設多變量常態，不符合時用 MLR（預設）；檢定變異 = 0 時有邊界問題，LRT 偏保守，p 可除以 2 作近似。
