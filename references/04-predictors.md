# 步驟三、四：預測變數

腳本：`step3_conditional.R`、`step4_tvc.R`

決策流程圖見 `00-flowcharts.md` 第 4、5 節。

## 1. 時不變預測變數

```
i + s ~ x1 + x2
```

| 參數 | 意義 |
|---|---|
| i ~ x | x 每增加 1 單位，起始水準的差異 |
| s ~ x | x 每增加 1 單位，每單位時間變化率的差異 |
| i、s 的平均 | **所有預測變數都等於 0 時**的起始水準與變化率 |
| i、s 的變異 | 控制預測變數後剩下的個別差異（殘差變異） |

**中心化**：預測變數的 0 沒有意義時（如年齡），用 `--center`，讓截距與斜率平均代表「平均的人」。

**交互作用**：`--interaction x1:x2` 會加入中心化後的乘積項。

**預測變數是否有用**：Grimm 指出，加入時不變預測變數通常不會明顯改變 CFI、RMSEA。要看：
- 階層式 LRT：與「路徑固定為 0」的基準模型比較（在 SEM 中，基準模型要包含預測變數，只是路徑為 0）。
- 個別路徑的估計值與 CI。

**解釋變異量**：(無條件變異 − 條件殘差變異) / 無條件變異。`step3_conditional.R` 同時報告這個指標與 lavaan 的 R²。

**預測軌跡圖**：把焦點預測變數設在平均 ±1 SD，其他固定在平均，畫出隱含軌跡（`predicted_by_covariate.png`）。這比係數表更容易讓讀者理解。

**這一步依賴的假設**：
- 所有人遵循同一種軌跡形式，不論預測變數的值。
- 成長因子的殘差變異與共變，以及觀察分數的殘差變異，不隨預測變數改變。

類別型預測變數可用多群組模型（步驟五）檢驗這些假設。

## 2. 時變共變數

```
t1 ~ b*c1
t2 ~ b*c2
t3 ~ b*c3
t4 ~ b*c4
```

- b 是同一波 c 與 t 的關聯，控制了成長趨勢。
- 加入後，截距與斜率是「控制時變共變數之後」的成長，解讀要改變。

`step4_tvc.R` 依序比較三個模型：

| 模型 | 設定 | 意義 |
|---|---|---|
| 相等-不相關 | 各波 b 相同；c 與 i、s 不相關 | 多層次模型的預設 |
| 自由-不相關 | 各波 b 不同 | 效果是否隨時間改變 |
| 自由-相關 | 再讓 c 與 i、s 相關 | 放寬多層次架構的限制（只有 SEM 能做） |

**為什麼要檢查相關**：多層次架構強制時變共變數與成長因子不相關，這個假設不成立時估計會有偏誤（Grimm；Curran & Peterman, 2005）。

**何時改用平行歷程模型**：時變共變數本身也在改變、且與結果可能互相影響（兩個都是內生變數）時，平行歷程模型更合適。改用 `sem-longitudinal` 的 `parallel_growth.R`。

**滯後效果**：要問時間順序時，改用前一波的值（`t2 ~ c1`、`t3 ~ c2`……），但會損失一波資料。

## 3. 遠端結果

`--distal z` 加入 `z ~ i + s`：斜率的係數是「控制起始水準後，變化率對結果的預測力」。
