# 步驟三：時不變預測變數

形式 linear；殘差 equal；時間 0, 1, 2, 3；預測變數 x1, x2, x1_x_x2（已中心化）。

預測變數平均：x1 = -0.092；x2 = 0.138。截距與斜率的平均是預測變數都等於 0 時的值。

## 配適

配適：χ²(14) = 13.14, p = .516, CFI = 1.000, TLI = 1.000, RMSEA = .000 [.000, .046], SRMR = .011（MLR，robust 指標）

- 加入預測變數的整體效果（基準模型：路徑固定為 0）：Δχ²(6) = 433.05, p < .001

加入時不變預測變數通常不會明顯改變 CFI、RMSEA 等整體指標；預測變數是否有用，要看上面的 LRT 與個別路徑（Grimm, 2017）。

## 本步驟依賴的假設

- 所有人遵循同一種軌跡形式，不論預測變數的值。
- 成長因子的殘差變異與共變，以及觀察分數的殘差變異，不隨預測變數改變。
- 這些假設可用多群組模型（步驟五）檢驗類別型預測變數（Grimm, 2017）。
