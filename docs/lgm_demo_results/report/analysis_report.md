## 解讀

- 加入時變共變數後，截距與斜率是「控制時變共變數之後」的成長，解讀要隨之改變。
- 效果是同一波的關聯，不代表因果方向；要問時間順序，可改用前一波的值（滯後效果）。
- 若時變共變數本身也在改變、且與結果互相影響，平行歷程模型（sem-longitudinal 的 parallel_growth.R）通常更合適（Grimm, 2017）。
