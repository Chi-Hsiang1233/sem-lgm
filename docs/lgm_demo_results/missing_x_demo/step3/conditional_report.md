# 步驟三：時不變預測變數

形式 linear；殘差 equal；時間 0, 1, 2, 3；預測變數 x1, x2。

預測變數平均：x1 = -0.115；x2 = 0.209。截距與斜率的平均是預測變數都等於 0 時的值。

預測變數有遺失：已改用 fixed.x = FALSE，讓 FIML 保留這些個案。

## 配適

配適：χ²(12) = 11.38, p = .497, CFI = 1.000, TLI = 1.001, RMSEA = .000 [.000, .054], SRMR = .020（MLR，robust 指標）

- 加入預測變數的整體效果（基準模型：路徑固定為 0）：Δχ²(4) = 343.91, p < .001

加入時不變預測變數通常不會明顯改變 CFI、RMSEA 等整體指標；預測變數是否有用，要看上面的 LRT 與個別路徑（Grimm, 2017）。

## 本步驟依賴的假設

- 所有人遵循同一種軌跡形式，不論預測變數的值。
- 成長因子的殘差變異與共變，以及觀察分數的殘差變異，不隨預測變數改變。
- 這些假設可用多群組模型（步驟五）檢驗類別型預測變數（Grimm, 2017）。
