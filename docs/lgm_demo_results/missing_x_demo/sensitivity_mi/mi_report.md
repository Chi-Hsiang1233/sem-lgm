# 多重插補（主結果）與 FIML 對照

- 模型：conditional_fit.rds（時不變預測變數的條件模型（步驟 3））。
- 插補：mice，42 組（有遺失者 41.2%）、迭代 10 次、亂數種子 20261112；連續變數用 pmm，二元變數用 logreg。
- 插補模型的變數：t1、t2、t3、t4、x1、x2；輔助變數 aux。
- 每組資料用和主分析相同的語法與設定估計（MLR），42 組都收斂，以 Rubin 規則合併。

FMI（缺失資訊比例）：因為遺失而損失的資訊占多少；越大代表這個參數越依賴遺失資料的處理方式。

## 簡易判讀

- ⚠ 斜率平均、斜率 ← x2 的差異超過 FIML 的 1 個 SE：結論對遺失資料的處理方式敏感，報告時兩種結果都列出並說明。
- FMI 介於 0.05–0.34。
- 多重插補多用了輔助變數；兩種方法的差異可能來自輔助變數提供的資訊，而不只是方法本身。要讓 FIML 也用到輔助變數，可用飽和相關法（auxiliary variables as saturated correlates）。
- FIML 與多重插補都假設 MAR；兩者一致不代表遺失不是 MNAR。MNAR 無法由資料檢驗，只能在限制中說明，必要時做 MNAR 模型的敏感度分析。
